About QuickNotes

QuickNotes keeps a plain text file at the centre of everything. There is no account, no sync and no proprietary format: your notes stay readable in any editor, forever. The interface exists only to make writing and retrieving them fast enough that you never lose a thought while opening a window.

How to use QuickNotes

  1. Press Ctrl + N to open a new note.
  2. Type your note, then add tags on the last line using the #tag syntax.
  3. Save with Ctrl + S; the note is appended to today's journal file.
  4. Press Ctrl + F and type a word or #tag to search every note.

Features

  • Instant full-text search across all notes
  • Inline #tags with automatic tag suggestions
  • Daily journal view grouped by date
  • Plain text storage with no lock-in
  • Optional local encryption for private notes

Keyboard shortcuts

Default shortcuts on Linux and Windows
Shortcut Action
Ctrl + N New note
Ctrl + S Save and close the current note
Ctrl + F Search all notes
Ctrl + K Jump to a tag
